## idealista — Search API (access request)

Da inviare tramite: https://developers.idealista.com/access-request

- Uso: ricerca accademica/personale non commerciale su prezzi di vendita
  residenziali (provincia di Trento, Italia).
- Territorio: provincia di Trento (comuni della provincia autonoma).
- Operazione: vendita (sale), tipologie residenziali (appartamenti, case,
  ville, rustici).
- Campi: prezzo richiesto, superficie, comune/zona, tipologia, locali/camere/
  bagni, data pubblicazione, URL annuncio.
- Frequenza: 1 run giornaliero, al più ~300 richieste/run, fuori orario di
  punta.
- Conservazione: archivio locale del progetto, non ridistribuito, con
  cancellazione su richiesta.
- Finalità: osservatorio dei prezzi richiesti nel tempo; nessun uso
  commerciale, nessuna rivendita dei dati.
